## Four Beats

1. **Name the circuit.** Give the HyDraw CAD circuit sheet a short title before you drop a valve.
2. **Pin the live symbols.** Keep current valves on the HyDraw CAD hydraulic schematic and leave unused blocks aside.
3. **Read the manifold.** Open HyDraw CAD manifold layout before you move a port that already has a note.
4. **Check the library.** Read the HyDraw CAD symbol library before you archive a valve.
5. **Close the loop.** Clear finished valves so the next HyDraw CAD visit does not start with a search.

## First Questions

**Does HyDraw CAD replace every other program?**
No. HyDraw CAD sits beside the lab list, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate HyDraw CAD profile.

**What should a new user try first?**
One small HyDraw CAD hydraulic schematic today, then the same circuit sheet tomorrow.

**Do manifold layouts leave the circuit sheet?**
No. HyDraw CAD manifold layout stays beside the same HyDraw CAD circuit sheet.

## Field Note

HyDraw CAD is easier to trust when the circuit sheet stays smaller than the folder it came from. A named circuit shows what is active, the symbol pins show what you will place today, and the closing note tells the next person which manifold port changed.
